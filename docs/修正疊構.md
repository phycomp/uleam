在高速與高頻電路板（PCB）的模擬領域中，「文字語法樹 $\rightarrow$ 幾何多邊形」的解析核心（Parser）如果只進行盲目的數值加減，會導致嚴重的硬體拓樸物理解析錯誤。
以下用純文字示意圖，為您直觀對比之前的錯誤解析以及本次修正的底層硬體邏輯核心：

## 1. 之前的錯誤解析：盲目堆疊法（Layer-by-Layer Stacking）
❌ 錯誤現象：導體兩側物理懸空、介電層板塊化分離。
在舊的邏輯中，解析器將「導電層（Conductor）」也當作一層具有厚度的實體板塊，直接從下往上硬性重疊。這會導致以下反常的硬體事實：

```
高度 (Y)
  ▲
  │   +-----------------------------------------------+
  │   |  L1_SOLDER_MASK (介電阻焊層厚度 25um)         |  <-- 蓋在金屬上方，與下層介電質分離
  │   +-----------------------------------------------+
  │              [懸空空氣]  +----------+  [懸空空氣]
  │                          | Diff_P   |                 <-- 金屬線獨立成一層厚片 (35um)
  │              [懸空空氣]  +----------+  [懸空空氣]
  │   +-----------------------------------------------+
  │   |  L3_PREPREG_1 (介電膠片層厚度 100um)          |  <-- 變成獨立的下方板塊
  │   +-----------------------------------------------+
  └───┴────────────────────────────────────────────────► 橫向寬度 (X)
```


* 為什麼不正確？
真實的防焊漆（Solder Mask）或介電質是液態塗佈或高壓壓合上去的。金屬線（Traces）的左右兩側應該被介電質滿滿地包裹著，而舊邏輯會讓金屬線左右兩側出現不應存在的「懸空空氣層」，這會讓 2D 場求解器計算出的特徵阻抗（Z₀）完全失真。


## 2. 修正後的解析重點：嵌入式拓樸演算法（Embedded Layer Topology）
✅ 修正重點：金屬貼附交介面、介電背景包覆。
新版 correct_hardware_parser 核心導入了真實 EDA 軟體的網格生成邏輯：「只有介電層會實質往上堆疊物理高度，金屬層則是依附在高度交介面上（X-Y 絕對多邊形），並將自身嵌入到背景中。」

```
高度 (Y)
  ▲
  │   +-----------------------------------------------+
  │   |  L1_SOLDER_MASK 背景 覆蓋範圍 -1000 到 +1000  |
  │   |          +----------+                         |  <-- 綠漆直接「包覆並吞噬」金屬線
  │   |          |  Diff_P  |                         |  <-- 金屬貼附在 L3 上沿，向上生長 35um
  │   +----------┴----------┴-------------------------+  <-- 【核心交介面 current_y】
  │   |                                               |
  │   |  L3_PREPREG_1 背景 (覆蓋範圍 -1000 到 +1000)  |  <-- 金屬線底座與介電質完美咬合
  │   |                                               |
  └───┴────────────────────────────────────────────────► 橫向寬度 (X)
```

## 🛠️ 代碼修正的核心三大關鍵：

   1. 分流指針控制（current_y 控制軸）：

   ```
   if l_type == "介電":
       current_y = y_top  # 只有介電層會把板子實體「往上推高」
   elif l_type == "導電":
       # 金屬層不推高背景，而是將頂點錨定在當前介面 [current_y 到 current_y + thick]
       current_y = y_metal_top  # 修正指針，讓下一層介電質完美銜接金屬上沿
   ```

   這確保了 L1_SOLDER_MASK 的下沿與 L3_PREPREG_1 的上沿在幾何上完全對接，金屬線則完美內嵌在兩者之間。

   2. 全多邊形矩陣化（np.array 頂點向量）：
   放棄了原先的 plt.Rectangle。所有金屬走線不論是單端、差動還是 Bus 總線，一律在 Parser 階段就被計算出四個頂點的向量：
   $$\text{v\_cond} = \begin{bmatrix} X_{left}, Y_{bottom} \\ X_{right}, Y_{bottom} \\ X_{right}, Y_{top} \\ X_{left}, Y_{top} \end{bmatrix}$$
   這使得後續加入蝕刻因子（Etch Factor 梯形側邊斜角）時，只需調整頂部的 $X$ 座標，Matplotlib 就能直接用 Polygon 畫出逼真的非矩形製程截面。

   3. 盲孔垂直海拔註冊表（layer_registry）：
   代碼中建立了一個實體海拔字典 **``` layer_registry[name] = {"bot": y_bot, "top": y_top}。 ```**
   當盲孔（Via）宣告「從 L2 穿透到 L4」時，Parser 不再盲目猜測高度，而是直接翻查註冊表，精確提取 L2 與 L4 的實體邊界，確保盲孔在多層板結構中不偏不倚地精確對接。

# 決策節點：Agent-First 代理人系統

## 節點 A：框架選型
- 問題：CrewAI / AutoGen / LangGraph / 混合？
- 決策：**混合 (LangGraph 編排 + CrewAI 角色)**
- 建議：LangGraph 保证控制流確定性與 checkpointing；CrewAI 提供角色抽象。

## 節點 B：整合範圍
- 問題：新增層 / 全面重構 / PoC？
- 決策：**全面重構為 Agent-First** (一次性完成)
- 建議：保留確定性工具層不變，降低風險。

## 節點 C：本地模型規格
- 硬體：RTX 5060 8GB VRAM
- 決策：**Llama3 8B Q4 (Ollama)**
- 建議：8B 是 8GB VRAM 的甜蜜點；70B 需 CPU offload (極慢)。

## 節點 D：Agent 角色
- 決策：**5 角色** (Optimizer, Physicist/Calculator, Guardrail, Reporter, Researcher)
- 建議：Physicist/Guardrail 保持確定性；LLM 僅 Researcher/Reporter。

## 節點 E：部署端點
- 決策：**Ollama (port 11434) + Llama3 8B**
- 建議：Ollama 安裝簡單、OpenAI 相容；vLLM 留作高吞吐備案。

## 節點 F：持久化
- 決策：**SQLite checkpointer (SqliteSaver)**
- 建議：支援中斷/恢復與除錯重播。

## 節點 G：可觀測性
- 決策：**Streamlit Agent Trace 頁面**
- 建議：每輪顯示節點/輸入/輸出/決策，利於除錯。

## 節點 H：工具層
- 決策：**確定性工具** (LLM 不心算物理)
- 建議：符合 skill.md guardrail；物理計算交給工具。

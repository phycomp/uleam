## 1. Stripline（帶狀線）

### 1.1 物理模型

```
    GND  y = +b/2
    ─────────────────────────────
         |  Dielectric εᵣ     |
         |                    |
    █████|████ Signal w   ████|█████  y = 0
         |                    |
         |  Dielectric εᵣ     |
    ─────────────────────────────
    GND  y = -b/2
```

### 1.2 關鍵特徵

| 特性 | 說明 |
|------|------|
| 傳播模式 | 純 TEM 模（均勻介質填充） |
| 有效介電常數 | $ε_{eff} = ε_r$（**精確成立**） |
| 屏蔽特性 | 雙接地平面，EMI 屏蔽最佳 |
| 頻率上限 | $f_{max} ≈ c/2b/\sqrt{εᵣ}$ |

### 1.3 保角映射精確解

$$Z_0 \cdot \sqrt{\varepsilon_r} = 30\pi \cdot \frac{K(k')}{K(k)}$$

其中 $k = \text{sech}(\pi w / 2b)$, $k' = \sqrt{1-k^2}$

### 1.4 工程閉式公式（Wadell / IPC-2141A）

**窄帶狀線**（$w/b \leq 0.35$）：

$$Z_0 = \frac{60}{\sqrt{\varepsilon_r}} \cdot \ln\left(\frac{8b}{\pi w}\right)$$

**寬帶狀線**（$w/b \geq 0.35$）：

$$Z_0 = \frac{94.15}{\sqrt{\varepsilon_r} \cdot \left(\dfrac{w}{b} + 0.441\right)}$$

### 1.5 厚度修正

$$w_{eff} = w - \Delta w$$

$$\Delta w = \begin{cases}
\dfrac{t}{\pi} \cdot \ln\left(\dfrac{2b}{t}\right) & w/b \leq 0.35 \\
\dfrac{t}{\pi} \cdot \ln\left(\dfrac{2\pi w}{t}\right) & w/b > 0.35
\end{cases}$$

> **注意**：厚度使邊緣場收斂，等效寬度**減少**（與 Microstrip 相反）。


## 2. Microstrip（微帶線）

### 2.1 物理模型

```
    Air ε₀
    ─────────────────────────────  y = y_max

    █████ Signal w, t █████  y = 0

    ─────────────────────────────  y = 0 (界面)
         |  Dielectric εᵣ  | thickness = h
         |                 |
    ─────────────────────────────  y = -h
    GND
```

### 2.2 關鍵特徵

| 特性 | 說明 |
|------|------|
| 傳播模式 | 準 TEM 模（非均勻介質） |
| 有效介電常數 | $1 < \varepsilon_{eff} < \varepsilon_r$ |
| 頻率上限 | $f_{max} \approx c / (4h\sqrt{\varepsilon_r})$ |
| 損耗 | 高於 Stripline（輻射損耗） |

### 2.3 有效介電常數（Hammerstad-Jensen）

$$\varepsilon_{eff} = \frac{\varepsilon_r + 1}{2} + \frac{\varepsilon_r - 1}{2} \cdot F\left(\frac{w}{h}\right)$$

**填充因子函數 $F(w/h)$**：

$$F\left(\frac{w}{h}\right) = \begin{cases}
\left(1 + \dfrac{12h}{w}\right)^{-1/2} + 0.04\left(1 - \dfrac{w}{h}\right)^2 & \dfrac{w}{h} \leq 1 \\
\left(1 + \dfrac{12h}{w}\right)^{-1/2} & \dfrac{w}{h} \geq 1
\end{cases}$$

### 2.4 特性阻抗

**窄微帶線**（$w/h \leq 1$）：

$$Z_0 = \frac{\eta_0}{2\pi\sqrt{\varepsilon_{eff}}} \cdot \ln\left(\frac{8h}{w} + \frac{w}{4h}\right)$$

**寬微帶線**（$w/h \geq 1$）：

$$Z_0 = \frac{\eta_0}{\sqrt{\varepsilon_{eff}} \cdot \left[ \dfrac{w}{h} + 1.393 + 0.667 \cdot \ln\left(\dfrac{w}{h} + 1.444\right) \right]}$$

### 2.5 厚度修正（Wheeler）

$$w_{eff} = w + \Delta w$$

$$\Delta w = \begin{cases}
\dfrac{t}{\pi}\left[\ln\left(\dfrac{4\pi w}{t}\right) + 1\right] & \dfrac{w}{h} \geq \dfrac{1}{2\pi} \\
\dfrac{t}{\pi}\left[\ln\left(\dfrac{2h}{t}\right) + 1\right] & \dfrac{w}{h} < \dfrac{1}{2\pi}
\end{cases}$$

> **注意**：厚度使邊緣場擴展，等效寬度**增加**。


## 3. CPW（共面波導）

### 3.1 物理模型

```
    Air ε₀
    ────────────────────────────────────────────────
         |         |         |         |
    GND  |   Slot  | Signal  |  Slot   |  GND
    █████    w     █████s█████   w     █████
         |         |         |         |
    ────────────────────────────────────────────────  y = 0
         |  Dielectric εᵣ    |  (thickness = h)
         |                   |
    ────────────────────────────────────────────────  y = -h
```

#### **參數定義**：
- $s$ = 中心導體寬度
- $w$ = 槽寬（中心導體到側邊地的距離）
- $d = s + 2w$ = 中心到中心的總寬度

### 3.2 關鍵特徵

| 特性 | 說明 |
|------|------|
| 傳播模式 | 準 TEM 模（表面波主導） |
| 有效介電常數 | $1 < \varepsilon_{eff} < (\varepsilon_r + 1)/2$ |
| 優勢 | 高頻損耗低、無需過孔接地、便於並聯元件 |
| 劣勢 | 需要較大表面積、易受封裝寄生影響 |

### 3.3 保角映射精確解（Wen, 1969）

$$Z_0 = \frac{30\pi}{\sqrt{\varepsilon_{eff}}} \cdot \frac{K(k')}{K(k)}$$

#### 其中：
- $k = \dfrac{s}{d} = \dfrac{s}{s + 2w}$
- $k' = \sqrt{1 - k^2}$
- $K(k)$ = 第一類完全橢圓積分

### 3.4 有效介電常數（有限厚度 $h$）

$$\varepsilon_{eff} = 1 + \frac{\varepsilon_r - 1}{2} \cdot q$$

**填充因子 $q$**：

$$q = \frac{K(k_1)/K(k_1')}{K(k)/K(k')}$$

#### 其中：
- $k_1 = \dfrac{\sinh(\pi s / 4h)}{\sinh(\pi d / 4h)}$
- $k_1' = \sqrt{1 - k_1^2}$

#### **極限行為**：
- $h \rightarrow \infty$: $q \rightarrow 1/2$, $\varepsilon_{eff} \rightarrow \dfrac{\varepsilon_r + 1}{2}$
- $h \rightarrow 0$: $q \rightarrow 0$, $\varepsilon_{eff} \rightarrow 1$

### 3.5 橢圓積分比 $K(k')/K(k)$ 的 Hilberg 近似

$$\frac{K(k')}{K(k)} \approx \begin{cases}
\dfrac{1}{\pi} \ln\left[\dfrac{2(1 + \sqrt{k'})}{1 - \sqrt{k'}}\right] & 0 \leq k \leq \dfrac{1}{\sqrt{2}} \\
\dfrac{\pi}{\ln\left[\dfrac{2(1 + \sqrt{k})}{1 - \sqrt{k}}\right]} & \dfrac{1}{\sqrt{2}} \leq k \leq 1
\end{cases}$$

精度 $< 3 \times 10^{-6}$，完全滿足工程需求。

### 3.6 厚度修正

$$s_{eff} = s + \Delta s, \quad \Delta s = \frac{t}{\pi}\left[1 + \ln\left(\frac{4\pi s}{t}\right)\right]$$


## 4. Differential Pair（差分對）

### 4.1 物理模型

**差分 Microstrip**：
```
    Air ε₀
    ────────────────────────────────────────────────

    █████   s   █████
    Line1       Line2
      w           w

    ────────────────────────────────────────────────  y = 0
         |  Dielectric εᵣ  |  (thickness = h)
    ────────────────────────────────────────────────  y = -h
    GND
```

**差分 Stripline**：
```
    GND
    ────────────────────────────────────────────────
         |  Dielectric εᵣ  |
    █████   s   █████
    Line1       Line2
      w           w
         |  Dielectric εᵣ  |
    ────────────────────────────────────────────────
    GND
```

### 4.2 偶模與奇模

| 模式 | 電壓關係 | 等效結構 | 物理意義 |
|------|----------|----------|----------|
| **偶模** | $V_1 = V_2 = V$ | 單條線對地 | 共模訊號 |
| **奇模** | $V_1 = +V, V_2 = -V$ | 單條線對虛擬地 | 差模訊號 |

### 4.3 差分阻抗定義

$$Z_{diff} = 2 \cdot Z_{0,odd}$$

$$Z_{cm} = \frac{Z_{0,even}}{2}$$

### 4.4 差分 Microstrip（Bryant & Weiss 公式）

**步驟 1**：計算單條線無耦合參數 $Z_{0,single}$ 和 $\varepsilon_{eff,single}$

**步驟 2**：耦合修正

對於 $w/h \leq 1$ 且 $s/h \leq 1$：

$$Z_{0,even} = Z_{0,single} \cdot \left[1 + \frac{0.2(w/h)^2}{s/h + w/h}\right]^{-1}$$

$$Z_{0,odd} = Z_{0,single} \cdot \left[1 - \frac{0.2(w/h)^2}{s/h + w/h + 0.5}\right]$$

**步驟 3**：差分阻抗

$$Z_{diff} = 2 \cdot Z_{0,odd}$$

有效介電常數修正：

$$\varepsilon_{eff,odd} = \varepsilon_{eff,single} \cdot \left[1 + 0.1\frac{w}{h}\exp\left(-1.5\frac{s}{h}\right)\right]$$

### 4.5 差分 Stripline（保角映射精確解）

$$Z_{0,even} = \frac{60}{\sqrt{\varepsilon_r}} \cdot \frac{K(k_e')}{K(k_e)}$$

$$Z_{0,odd} = \frac{60}{\sqrt{\varepsilon_r}} \cdot \frac{K(k_o')}{K(k_o)}$$

#### 其中：
- $k_e = \tanh\left(\dfrac{\pi w}{2b}\right) \cdot \tanh\left(\dfrac{\pi(w+s)}{2b}\right)$
- $k_o = \tanh\left(\dfrac{\pi w}{2b}\right) \Big/ \tanh\left(\dfrac{\pi(w+s)}{2b}\right)$
- $k_e' = \sqrt{1 - k_e^2}$, $k_o' = \sqrt{1 - k_o^2}$

**差分阻抗**：

$$Z_{diff} = 2 \cdot Z_{0,odd}$$



## 6. 數值驗證

### 6.1 驗證案例

| 截面 | 案例 | 幾何參數 | 解析結果 |
|------|----|-------------|-------|
| **Microstrip** | 50Ω 設計點 | w=2.9mm, h=1.6mm, εᵣ=4.2 | Z₀=52.95Ω |
| **Stripline** | 50Ω 設計點 | w=0.3mm, b=3.2mm, εᵣ=4.2 | Z₀=52.02Ω |
| **CPW** | 典型 | s=0.5mm, w=0.3mm, h=1.6mm | Z₀=78.33Ω |
| **Diff Microstrip** | DDR4 | w=0.15mm, s=0.15mm, h=0.2mm | $Z_{diff}=155.5Ω$ |
| **Diff Stripline** | 緊密耦合 | w=0.1mm, s=0.1mm, b=0.2mm | $Z_{diff}=57.95Ω$ |

### 6.2 極限行為驗證

| 截面 | 極限 | 預期行為 |
|------|------|----------|
| Microstrip | w/h → ∞ | $ε_{eff} → ε_r, Z₀ ∝ h/w$ |
| Microstrip | w/h → 0 | $ε_{eff} → (ε_r+1)/2$ |
| Stripline | w/b → ∞ | Z₀ ∝ b/w |
| CPW | h → ∞ | $ε_{eff} → (ε_r+1)/2$ |
| CPW | s/w → ∞ | Z₀ → ∞ |
| Diff Stripline | s → ∞ | Z₀e ≈ Z₀o |

# 優化報告 (權重調整後)

## 目標
完整多目標：阻抗匹配 50Ω + 串擾最小化 + 熱負載控制。

## 方法
numpy grid search over w (0.10-0.39) × h (0.10-0.39) × s (0.20/0.30/0.40), er=3.4, t=10μm.

cost = |Z0-50| + |NEXT+60| + thermal/1000

## 結果
- 最佳：w=0.19mm, h=0.10mm, s=0.40mm
- Z0 = 49.88 Ω (err -0.12)
- NEXT = -40.59 dB
- thermal = 283.87 μW/ch
- cost = 19.805

## 優化後情境驗證
- CF3-opt: Z0=49.885 (PASS)
- FPC-opt: Z0=49.355 (PASS)
- Uleam1-opt: Z0=44.136 (FAIL, 需個別調 er)

## 建議
- 權重調整 (w=0.19, h=0.10) 有效命中 50Ω。
- 串擾目標 -60dB 未達，增大 s 或降低 er。
- Uleam1 (er=3.5) 需獨立優化。
- 後續加入製程良率與熱負載至成本函數。
